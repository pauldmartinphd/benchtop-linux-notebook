## Firefox

- Firefox is installed from Flathub (`org.mozilla.firefox`) in each user's own Flatpak installation, once, by the user service `tcbl-firefox.service`, after Flathub is added; a user who removes it does not get it back. While offline it retries every 10 minutes. A Firefox the user already has, in either installation, counts as installed. The USB's tik and Create User accounts have no Flathub and get no Firefox. Not yet tested on a machine. benchtop-settings `0ed91d8`.
- Firefox is the default browser, in place of Brave, because it is what most people expect. Nothing sets it explicitly: it is the only browser installed, so GNOME uses it.
