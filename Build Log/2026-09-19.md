## Notes: tik checked against its source

Dated September 19 in the installer design notes. Checked against tik's upstream source (main), which may differ slightly from the packaged version.

- Encryption does not depend on the tik config package: tik always creates a temporary key file and passes it to systemd-repart, so tik-config-generic encrypts as tik-config-Aeon does.
- tik runs systemd-repart without --definitions, so the image's /usr/lib/repart.d files are the ones used.
- Custom modules run in a separate pass after all shipped post modules, so 16-tcbl-reseal runs after 15-encrypt whatever its number.
- Still open: the GPT type of the image's root partition (CopyBlocks=auto with Type=root fails if kiwi labels root with the generic Linux type), and whether a second TPM enrollment replaces the first.
