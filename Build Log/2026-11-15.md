## PackageKit arrived with an update

- On silversurfer, GNOME Software offered system updates, and applying them did nothing: PackageKit had been installed. The chain: `gnome-software` recommends `gnome-software-plugin-packagekit`, which requires `PackageKit`. The image installs only required packages (kiwi runs zypper with `--no-recommends`, seen in the image's build log), and the installer's package sets use `--no-recommends`, but updates followed zypper's default, which installs recommended and supplementing packages; YaST arrived the same way on October 30. Aeon leaves that default; MicroOS sets `solver.onlyRequires = true`.
- Fix: tc-benchtop-settings sets `solver.onlyRequires = true` (`/usr/etc/zypp/zypp.conf.d/90-tcbl-only-requires.conf`), so updates keep the package set of a new installation; whatever TCBL needs is listed in its patterns. The image already relies on no recommended package. benchtop-settings `50c9545`.
- On silversurfer: remove PackageKit and its GNOME Software plugin with a transactional update, then compare its packages with the image's to find what else updates added.
