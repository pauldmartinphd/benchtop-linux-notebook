## OBS: health-checker

- rev 1 16:52. rev 2 16:56: TCBL patch to roll back without a reboot and never start an emergency shell (health-checker-rollback-without-reboot.patch). health-checker.conf uses kernel.panic instead of panic, as in request 1380231 to devel:microos.
- The patch applies to systems booted through a BLS boot loader. When the booted entry has not passed the checks before (boot counting still in effect, as for a snapshot an update created), the newest other snapshot whose entry passed becomes the default, so the next boot rolls back to it. Otherwise the failure is only logged. The rollback target comes from the boot entries (systemd-bless-boot removes the boot counter of an entry that passed), not from a state file in /var.
