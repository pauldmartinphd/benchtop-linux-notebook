## Ideas

- Nautilus: the third-party My Computer view (drives with usage bars, a column view) and Sushi, for a Nautilus Flatpak built by TCBL. The view injects itself into Nautilus's widgets rather than using a public API, so it would be built and tested with a fixed Nautilus version. Recorded in GNOME Configuration.
- Ubuntu's AI launcher prototype (`warty-prototype`, a scripted mockup with no model running) to be tracked. Recorded in GNOME Configuration.
- macOS's Emacs text keys on Control. On GNOME, Control is the application key; GTK 3 has an Emacs key theme without a kill buffer, GTK 4 has none, and only a remapper that moves application commands to Super would cover every app. Recorded in Input Devices; it conflicts with the Modal Keys idea.

## Gaming

- Epic's Easy Anti-Cheat v2 for Linux requires Secure Boot, TPM 2.0, IOMMU, the BPF LSM, kexec disabled, and a kernel and modules signed with well-known keys. The planned TCBL kernel and the TCBL-signed ZFS module probably do not qualify, so a gaming boot entry would use openSUSE's kernel-default. Recorded in Gaming Mode.
