## Hibernation

- Matthew Garrett's patch set for hibernation under lockdown (LWN, November 6) recorded in the hibernation TODO in [Build Configuration](../Build%20Configuration.md) as the preferred route if it lands: openSUSE's kernel could then hibernate with lockdown, without a TCBL kernel. It needs firmware that caps PCR 5, and its PCR 5 marker would change the PCR that TCBL's disk key is sealed to.
- Correction: the main reason for a TCBL kernel is driver support and the linux-surface patches, not hibernation; Build Configuration now says so, with a TODO for it. The upstream hibernation route would remove one item from the custom kernel, not the reason for it.
