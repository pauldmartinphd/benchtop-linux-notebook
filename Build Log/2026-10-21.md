## Tumbleweed repositories

- Design: installed systems update from the Tumbleweed repositories, with repo-tcbl layered on top at priority 90.
- Finding: Build31.1 shipped only repo-tcbl. openSUSE-repos was missing from the hand-trimmed pattern, so installed systems had no Tumbleweed repository.
- Fix: Requires openSUSE-repos-Tumbleweed. The bare openSUSE-repos capability is provided by four flavors (Leap, MicroOS, Slowroll, Tumbleweed) and would leave OBS with a choice. The package adds the repositories through a zypp service at the default priority 99.
- With the Tumbleweed repositories present, the installer's optional package sets resolve their dependencies at install time.
